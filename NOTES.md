# Аддон «шекель» для WoW Forever: заметки исследования

Дата: 2026-11-25.

## Статус
MVP 0.1 (сборка 1) в `Shekel/`, скопирован в `_forever_/Interface/AddOns/Shekel`. В игре ещё не проверен.
Есть: полный скан (`ReplicateItems`, подхватывает и скан Auctionator), история цен по дням,
рецепты из окна профессии, цены торговцев, вкладки «Крафт» (порог прибыли и маржи) и «Цены» (поиск).
Команды: `/shekel` (`/shk`) — окно, `/shekel scan` — скан, `/shekel build` — номер сборки.
Синтаксис и логика цен/крафта проверены на заглушках (lupa). Вкладки «Фарм» и обучения по луту ещё нет.

Сборка 2: все профессии. `Shekel/Data/Recipes.lua` собирается `tools/build_recipes.py` из vmangos:
1133 рецепта (ключ = id заклинания = recipeID в игре), источник (учитель / предмет-рецепт),
цены реагентов у торговцев. Приоритет: мои рецепты > увиденные в окне профессии (`ShekelDB.seen`,
в т. ч. чужие по ссылке и новые рецепты Forever) > база. Во вкладке «Крафт»: «Все / Мои рецепты», выбор профессии.

Сборка 3 (после первой проверки в игре):
- `ReplicateItems` в Forever снимок не присылает (скан висел 2 минуты). Скан переделан на обычный поиск:
  `SendBrowseQuery` + `RequestMoreBrowseResults`, как у Auctionator по умолчанию. Цена = минимальный выкуп за штуку.
  Результаты обычных поисков игрока тоже сохраняются. Есть полоса загрузки и итог «отсканировано N предметов».
- В шрифте игры нет «·», «−», «…», «×», «–» — показывались квадратами. Не использовать в строках; «—» есть.
  Одиночный `|` в строке — управляющий символ, писать `||`.
- Вкладка «Фарм»: `Data/Loot.lua` из `tools/build_loot.py` — 1958 обычных мобов (шансы, монеты, серый хлам, шкуры)
  и 66 узлов травы/руды с нужным навыком. Доход за убийство = монеты + хлам + добыча по цене аукциона −5%
  (нет на аукционе — цена торговца). Зона моба — из QuestieDB (`NpcDB.zoneID`), он стоит у пользователя.

Сборка 8: названия предметов — по событию `ITEM_DATA_LOAD_RESULT` (ответ на `RequestLoadItemDataByID`),
хранятся в `ShekelDB.names`/`quality`. Данные скана переживают перезаход (были и раньше).

Сборка 9 (четыре улучшения):
- Честные цены (`Prices.lua`): медиана дневных цен за 14 дней; цена > 2× медианы — «задрана», для продажи
  берётся медиана (`ns.SellPrice`). Спрос `ns.Demand`: сумма уменьшений количества между полными сканами в день
  (снимки `r.s`, до 40). Включает снятые/истёкшие лоты — оценка сверху.
- Вкладка «Торговцу» (`Flip.lua`): лоты дешевле цены продажи торговцу (`ShekelDB.sell`, из GetItemInfo).
- Обучение по луту (`Learn.lua`): убийство = новый GUID трупа в LOOT_READY (журнал боя закрыт);
  повторное открытие с другими предметами = шкуры. `ShekelDB.learn.mobs/nodes`. В фарме доход смешивается:
  вес своих данных k/(k+15) при k ≥ 3; новые мобы Forever появляются сами. Сессия фарма: золото в час.
- Список покупок (`Shop.lua`, правый клик на крафт): учёт сумок и банка, предупреждение о нехватке на аукционе,
  поиск/сохранение списка через Auctionator API v1. Цены в подсказке любого предмета (`Tooltip.lua`,
  `TooltipDataProcessor`), автоскан при открытии аукциона если скан старше часа, «В мире» — число спавнов.
- Команды: `/shekel help`, `tooltip`, `autoscan`, `minimap`, `scan`, `build`.
- Не сделано: точная стоимость закупки по глубине стакана (нужен поиск по предмету, не проверен на Forever).

Сборка 10 — выкуп для перепродажи торговцу (`Buyer.lua`):
- Вкладка «Торговцу»: галочки, «Выбрать все», «Снять выбор», «Выкупить выбранное».
- Поиск: `SendSearchQuery(MakeItemKey(id))`, ждём `ITEM_SEARCH_RESULTS_UPDATED`/`COMMODITY_SEARCH_RESULTS_UPDATED`;
  без `GetItemKeyInfo` в кэше сервер игнорирует поиск — ждём его. Свои лоты (`containsOwnerItem`) пропускаем.
- Покупка только по клику (защищённые функции): штучный лот — `PlaceBid`, успех по списанию денег;
  «товар» — `StartCommoditiesPurchase` → `COMMODITY_PRICE_UPDATED` (если цена ≥ торговой — Cancel) →
  второй клик `ConfirmCommoditiesPurchase` → `COMMODITY_PURCHASE_SUCCEEDED/FAILED`. Предел трат в золоте.
- Купленное: `ShekelDB.flipBought[itemID]`. У торговца кнопка «продать купленное» — только целые стопки
  не больше купленного (`C_Container.UseContainerItem` с паузой 0,15 с). Покупки приходят на почту.
- Проверено на имитации; на живом сервере поиск и покупка ещё не проверены.

Сборка 25 — большое улучшение:
- Вкладка «Главное» (первая, открывается у аукциона): по 3 лучших действия — крафт (мои рецепты, по прибыли в день),
  перепродажа, фарм на моём уровне, подешевевшее избранное. Клик по строке — действие.
- Надёжность цены `ns.Confidence` (зелёный/жёлтый/красный значок Interface\COMMON\Indicator-*): свежесть скана,
  задранная цена, спрос, история, количество. В таблицах у цен и в подсказках.
- Крафт: «В день» = прибыль x min(1/перезарядка, спрос/выход); перезарядки по классике (трансмутации, луноткань).
  Цена выставления `ns.PostPrice`: на медь дешевле самого дешёвого лота, но не ниже 80% обычной.
- Фарм: правый клик — метка на карте (`Map.lua`: QuestieDB spawns + Questie ZoneDB → `C_Map.SetUserWaypoint`);
  режим «Зоны» (3 лучших моба зоны) и «Твоё в час» по зонам (`ShekelDB.learn.zones`, `ns.ZoneGoldPerHour`).
- Избранное (`Watch.lua`): Alt+клик по строке; оповещение в чат + звук, если цена < 75% обычной (раз в 30 мин).
- Окно: рамка как у окон игры (BackdropTemplate, золотой край), высота меняется уголком, кнопка «Настройки» с галочками.
При правках поднимать `ns.BUILD` в `Core.lua` и копировать папку в игру заново.

## Идея
1. Сканировать аукцион и хранить историю цен.
2. Вкладка «Фарм»: что дорого стоит и легко добывается (с учётом профессий игрока).
3. Вкладка «Крафт»: купить реагенты → скрафтить → продать, с учётом 5% комиссии и залога, с порогом прибыли.
Аддон только показывает. Покупка и выставление — кликами игрока.

## База дропа: vmangos
- Источник: релиз `db_latest` в github.com/vmangos/core, файл `db-sqlite-34aeaa8.zip` (21.11.2026).
- Лежит в `data_src/vmangos/` (146 МБ после распаковки, в git не класть).
- Нужные таблицы: `creature_loot_template`, `skinning_loot_template`, `gameobject_loot_template`,
  `reference_loot_template` (общий мировой дроп, ссылки через отрицательный `mincountOrRef`),
  `creature_template` (уровни, `loot_id`), `item_template` (`bonding`, `sell_price`),
  `npc_vendor`, `locales_item`/`locales_creature` (`name_loc8` — русские названия).
- В `item_template` и `creature_template` по несколько строк на запись (столбец `patch`): брать последнюю.
- Проверка: Волшебная пыль (2091) падает с Пыльного демона (832, ур. 18–19) с шансом 15%, как и на сервере.

Оценка `tools/survey_vmangos.py` (только обычные мобы открытого мира, шанс ≥ 1%, предмет продаётся):
- моб → предмет: 11 195 пар, снятие шкур: 1 847, руда/трава/сундуки: 835;
- 781 продаваемый предмет падает с мобов, у 427 есть источник с шансом ≥ 10%;
- таблица для аддона ~180 КБ без мирового дропа (reference) — помещается спокойно.

## Что в WoW Forever отличается (официальная игра Blizzard, вышла 04.11.2026)
Источники: warcrafttavern.com/forever/guides/overview, warcraft.wiki.gg/wiki/WoW_Forever.
- Новые зоны (Mount Hyjal, Riverglades, Shen'dralas, Zephras Isle), новые подземелья и мобы — их нет в vmangos.
- В профессиях новые материалы и десятки новых и переделанных рецептов; новые точки добычи в стартовых зонах.
- Есть NPC «чёрного рынка», которые продают некоторые материалы по фиксированной цене — это потолок цены, учитывать.
- Аукцион с интерфейсом из современного WoW; игроки на «мега-реалме» на набор правил и регион —
  значит, аукцион, вероятно, общий и большой. Возможно, API аукциона современный (`C_AuctionHouse`), а не классический.
- По новостям, Blizzard меняет шансы выпадения патчами.

## Решения по архитектуре
- vmangos — только стартовая оценка. Поверх неё аддон учится на луте игрока: какой моб (NPC id из GUID
  источника добычи) сколько раз убит и что выпало. Наблюдаемые шансы постепенно заменяют базовые.
- Предметы и мобы, которых нет в базе, появляются только из наблюдений.
- Рецепты не брать из vmangos: аддон запоминает их из окна профессии в игре — так новые рецепты Forever учтутся сами.
- Цены торговцев и чёрного рынка запоминать при открытии окна торговца.
